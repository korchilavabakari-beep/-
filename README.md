# ავტორენტი — ავტომობილების გაქირავების პორტალი

საკურსო პროექტი 3. სუფთა HTML + CSS + JavaScript (ბიბლიოთეკების ინსტალაციის გარეშე).

## გაშვება
გახსენით `index.html` ბრაუზერში (ორჯერ დაწკაპუნებით). საუკეთესო შემთხვევაში გაუშვი ლოკალური სერვერით:

    python -m http.server 8000     # შემდეგ გახსენით http://localhost:8000

## ფაილები
| ფაილი | დანიშნულება |
|---|---|
| `index.html` | გვერდის ჩონჩხი |
| `css/style.css` | დიზაინი |
| `js/config.js` | **API ენდპოინტები და მოთხოვნის/პასუხის ფორმატი — აქ ცვლით API-ს მორგებას** |
| `js/api.js` | რეალური API-ს კლიენტი + `Data` ფასადი |
| `js/demo.js` | დემო მონაცემები (localStorage)
| `js/util.js` | დამხმარე ფუნქციები |
| `js/app.js` | როუტერი და ყველა გვერდი |

## რეჟიმები (`js/config.js` → `MODE`)
- `'auto'` (ნაგულისხმევი) — ჯერ რეალური API, თუ ვერ დაუკავშირდა — დემო
- `'api'` — მხოლოდ რეალური API
- `'demo'` — მხოლოდ დემო
